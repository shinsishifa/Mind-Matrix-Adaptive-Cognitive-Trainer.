# 🧠 Mind Matrix — Cognitive IQ Trainer

**Mind Matrix** is an interactive web app built with Vanilla JavaScript, HTML5, and CSS3 designed to challenge spatial working memory, sequence recall, and processing speed through adaptive pattern scaling.

---

## 🌟 Key Features

* **Modular File Structure:** Built with separated `index.html`, `style.css`, and `script.js` files.
* **Adaptive Speed Progression:** Memory sequences lengthen and playback speeds accelerate dynamically as level rank increases.
* **Live Cognitive Estimator:** Evaluates performance levels and dynamically scales a relative performance index score.
* **Zero External Dependencies:** Native DOM logic with smooth CSS grid rendering.
